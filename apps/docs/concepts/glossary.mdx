<ResponseField name="AAL">Authentication assurance level: `aal1` after a password or link, `aal2` after a second factor. Policies check it with `{"aal": "aal2"}` or the built-in `mfa` policy.</ResponseField>
<ResponseField name="Akountz">The identity service: users, sessions, OAuth, MFA, organizations, roles and permissions.</ResponseField>
<ResponseField name="Angula">The realtime service: channels, presence, history.</ResponseField>
<ResponseField name="API key">A credential for one project environment. Publishable (`pb_pk_…`) or secret (`pb_sk_…`), optionally scoped.</ResponseField>
<ResponseField name="Atlas">Sillo's OpenAPI reference UI, used for each environment's generated docs.</ResponseField>
<ResponseField name="Block">One step in a flow, such as `resource.create`, `control.if` or `mail.send`. There are 58 built in.</ResponseField>
<ResponseField name="Bucket">A named storage area with read/write policies, accepted types and a size limit.</ResponseField>
<ResponseField name="Channel">A realtime topic (`chat:lobby`, `resource:notes`), governed by channel rules.</ResponseField>
<ResponseField name="Channel rule">A pattern plus subscribe/publish policies, presence and history settings for matching channels.</ResponseField>
<ResponseField name="Compiled app">The Sillo application generated for one environment from its definitions.</ResponseField>
<ResponseField name="Condition">The JSON expression a policy evaluates: shorthands, comparisons, checks and `all`/`any`/`not` groups.</ResponseField>
<ResponseField name="Context (platform)">The signed `X-Pawabase-Context` the gateway adds: project, environment, key id, role, scopes.</ResponseField>
<ResponseField name="Custom route">An endpoint under `/rest/v1` handled by a flow or a function.</ResponseField>
<ResponseField name="Definition">Any stored JSON document describing part of the backend (resource, policy, flow…).</ResponseField>
<ResponseField name="Environment">An isolated instance of a project with its own data, keys, secrets, users and infrastructure.</ResponseField>
<ResponseField name="Event">A named fact (`invoices.created`) with a payload, recorded and fanned out to consumers.</ResponseField>
<ResponseField name="Expand">`?expand=relation` on a resource request: includes related rows.</ResponseField>
<ResponseField name="Extension route">A plain Sillo router in project code, mounted under `/rest/v1/x/`.</ResponseField>
<ResponseField name="Flow">A graph of blocks triggered by HTTP, events, resources, schedules, webhooks, realtime or jobs.</ResponseField>
<ResponseField name="Function">An async Python function in project code registered with `@function`.</ResponseField>
<ResponseField name="Gateway">The only public entry point (port 8080).</ResponseField>
<ResponseField name="Inbound hook">A public, verified URL that turns third-party webhooks into events or flow runs.</ResponseField>
<ResponseField name="Kit">The shared library (`packages/kit`) with the policy and flow engines.</ResponseField>
<ResponseField name="Operator">A person using Studio; a user of the reserved `_platform` project.</ResponseField>
<ResponseField name="Owner field">A resource field set to the caller's user id on create, server-side.</ResponseField>
<ResponseField name="Policy">A named, reusable condition deciding whether an operation may proceed.</ResponseField>
<ResponseField name="Promotion">Copying definitions from one environment to another. Data, keys and secrets never move.</ResponseField>
<ResponseField name="Pushdown">Turning policy conditions on record fields into SQL `WHERE` clauses for list requests.</ResponseField>
<ResponseField name="Resource">A table plus its API, validation, access, relations and behaviour.</ResponseField>
<ResponseField name="Schema">A reusable field set compiled to a Pydantic model.</ResponseField>
<ResponseField name="Secret">An encrypted per-environment value, referenced as `secret://NAME`.</ResponseField>
<ResponseField name="Sillo">The Python framework Pawabase is built on.</ResponseField>
<ResponseField name="Studio">The control plane UI (port 8090).</ResponseField>
<ResponseField name="Subscription">A rule sending matching events to a flow, function or realtime channel.</ResponseField>
<ResponseField name="Template (flow)">A `{{ path }}` lookup in block configuration: `{{ input.body.email }}`.</ResponseField>
<ResponseField name="Transformer">Declarative response shaping: omit, pick, set, rename, case.</ResponseField>
<ResponseField name="Version">The environment's definitions counter; each change increments it.</ResponseField>
