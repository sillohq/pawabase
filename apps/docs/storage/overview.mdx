## Overview

**Storage** in Pawabase is built around **buckets** — named containers for objects with per-bucket policies. Every bucket has its own access control, driver configuration, and content safety settings.

## How Storage Works

Storage operations follow a consistent pattern: the client requests access through the gateway, the policy engine evaluates permissions, and the driver performs the actual read or write operation.
