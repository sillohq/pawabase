## Configuring Drivers

Each driver has its own configuration parameters. Common configuration options include region, credentials, and bucket settings.
```yaml
- name: "documents"
  driver: "s3"
  driver_config:
    region: "us-east-1"
    access_key: "$AWS_ACCESS_KEY"
    secret_key: "$AWS_SECRET_KEY"
    bucket: "my-bucket"
```

## Driver-Specific Options

| Driver | Option | Description |
| --- | --- | --- |
| S3 | region | AWS region |
| S3 | endpoint_url | Custom endpoint for S3-compatible services |
| GCS | project_id | GCP project identifier |
| GCS | bucket | GCS bucket name |
| Azure | container | Azure container name |
| Local | base_path | Base directory for file storage |

## Best Practices

**1. Use S3 for production AWS deployments**
**2. Use GCS for GCP-native applications**
**3. Use Local only for development and testing**
**4. Configure appropriate retry policies**
