## Creating a Bucket

To create a bucket, define it in your configuration:
```yaml
- name: "avatars"
  driver: "s3"
  read_policy:
    "eq": ["$auth.org", "acme"]
  write_policy:
    "in": ["$auth.roles", ["admin"]]
  content_safety: true
```

## Bucket Configuration

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| name | string | Yes | Unique bucket name |
| driver | string | Yes | Storage backend |
| read_policy | object | No | Who can read objects |
| write_policy | object | No | Who can write objects |
| content_safety | boolean | No | Enable content scanning |
| max_size | number | No | Maximum file size in bytes |
| allowed_types | array | No | Allowed MIME types |
