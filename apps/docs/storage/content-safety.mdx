## How Content Safety Works

```mermaid
sequenceDiagram
    Client->>Gateway: Upload file
    Gateway->>Scanner: Scan file
    Scanner-->>Gateway: Scan result
    alt Clean
        Gateway->>Driver: Store file
    else Infected
        Gateway-->>Client: Reject file
    end
```
