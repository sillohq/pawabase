## Message Structure

Every message conforms to this base structure:
```json
{
  "type": "subscribe",
  "channel": "store:7",
  "payload": {}
}
```

| Field | Type | Description |
| --- | --- | --- |
| type | string | Message type |
| channel | string | Channel name for channel messages |
| payload | object | Message-specific data |

## Message Types

### Client-to-Server

| Type | Description | Direction |
| --- | --- | --- |
| subscribe | Subscribe to a channel | Client → Server |
| unsubscribe | Unsubscribe from a channel | Client → Server |
| publish | Publish a message to a channel | Client → Server |
| presence | Update presence metadata | Client → Server |
| ping | Heartbeat | Client → Server |

### Server-to-Client

| Type | Description | Direction |
| --- | --- | --- |
| subscribed | Acknowledgment for subscribe | Server → Client |
| unsubscribed | Acknowledgment for unsubscribe | Server → Client |
| message | New message on a channel | Server → Client |
| presence_changed | Presence update | Server → Client |
| history | Historical messages | Server → Client |
| error | Error response | Server → Client |

## Subscribe Message

To subscribe to a channel, send a message with type `subscribe`:
```json
{
  "type": "subscribe",
  "channel": "store:7",
  "payload": {
    "user_id": "user-123"
  }
}
```

The server responds with a `subscribed` acknowledgment:
```json
{
  "type": "subscribed",
  "channel": "store:7",
  "status": "ok"
}
```

## Publish Message

To publish a message to a channel, send a message with type `publish`:
```json
{
  "type": "publish",
  "channel": "store:7",
  "payload": {
    "event": "item_added",
    "data": { "name": "Widget" }
  }
}
```
