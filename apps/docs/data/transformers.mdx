A **transformer** reshapes what consumers see without changing what's stored: hide internal fields, add computed links, rename for a mobile client.

## Steps

Steps always run in this order, regardless of how you write them:

| # | Step | Takes | Effect |
| --- | --- | --- | --- |
| 1 | `omit` | list of field names | Remove fields |
| 2 | `pick` | list of field names | Keep only these fields |
| 3 | `set` | `{field: value}` | Add or overwrite; values may use `{{ record.… }}` templates |
| 4 | `rename` | `{from: to}` | Rename keys |
| 5 | `case` | `"camel"` or `"snake"` | Convert every key's case |

```json
{
  "name": "report_card_view",
  "definition": {
    "omit": ["guardian_user_ids"],
    "set": { "pdf_url": "https://brightfield.example/report-cards/{{ record.id }}.pdf" }
  }
}
```

## Applying a transformer

- On a **resource**: `"transformer": "report_card_view"` shapes every `list` and `get` response and every write's returned record.
- On a **custom route**: shapes the handler's response.
- In a **flow**: the `transform.map` block applies any transformer to any value.

Transformers apply to **responses only**. Policies and flows always see the full stored record.

<Warning>
A transformer is presentation, not access control. `omit` hides a field from responses, but anyone who can write the resource can still set it. Protect sensitive writes with `read_only` fields and policies.
</Warning>

## Examples

<CodeGroup>
```json Public profile
{ "pick": ["id", "title", "first_name", "last_name", "email", "department_id"],
  "set": { "profile_url": "https://school.example/staff/{{ record.id }}" } }
```
```json Mobile camelCase
{ "omit": ["author_id"], "case": "camel" }
```
```json Friendly names
{ "rename": { "created_at": "joined" }, "omit": ["password_hash"] }
```
</CodeGroup>

## Python transformers

When shaping needs logic (formatting money per locale, merging fields), register one in project code:

```python code/school/transformers.py
from pawabase_kit.transformers import transformer

@transformer("invoice_summary")
def invoice_summary(record, context):
    return {
        "number": record["invoice_no"],
        "outstanding": f'{record["currency"]} {record["balance"]:,.0f}',
        "is_overdue": record["status"] == "overdue",
    }
```

Reference it by name like a declarative one. See [Python extensions](/code/python-extensions).
