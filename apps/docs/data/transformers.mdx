## Overview

Transformers rewrite resource responses. A transformer is a Python function that receives the record data and returns a modified version of it.

Transformers are configured in the resource definition's transformer field. They run after the policy gate but before the response is returned to the caller.

## Transformer function signature

The transformer function receives the record as a dictionary and returns a modified dictionary. The function has access to all fields in the record and can add, remove, or modify fields.

```python
def transformer(record):
    # Add a computed field
    record["display_price"] = record["cost"] * 1.2
    # Remove sensitive fields
    record.pop("internal_cost", None)
    return record
```

## Use cases

Transformers are useful for: adding computed fields, formatting dates and numbers, hiding internal data from API consumers, and enriching responses with additional context.

For example, a transformer can add a display_price field that is cost * 1.2 while keeping the cost field completely hidden from the response.

## Transformer and caching

Transformer output is included in the cached response. When cache_ttl is enabled, the transformed response is cached per-caller. Cache invalidation happens automatically on every write operation.

## Transformer and events

Events emit the original record data, not the transformed data. The transformer only affects the API response, not the event payload.

## Transformer and the database console

Transformers only apply to API responses. The database console returns raw SQL results without transformation. This means you can see the original data through the console even if the API response is transformed.

## Best practices

Keep transformer functions simple and focused. They should not make external API calls or perform expensive computations.

Use transformers for presentation logic, not for business logic. Business logic belongs in policies or custom routes.

Test transformer functions thoroughly. They affect every response for the resource.
