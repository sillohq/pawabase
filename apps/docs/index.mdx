Pawabase is a backend platform for building complete application backends and business systems. You design the backend in Pawabase Studio, then connect a web, mobile, server, or external integration through supported public APIs.

It can power a focused application or a serious operational system: a SaaS workspace with organizations and permissions; a marketplace with listings, payments, and webhooks; a logistics system with queued dispatch work and live status; or an HR platform with approval flows, scheduled reminders, files, and audit history.

<Callout>
Pawabase is not simply a database with an API attached. Resources provide durable data and generated APIs; authentication and policies secure them; storage and realtime connect applications; and flows, events, queues, schedules, webhooks, and custom routes implement the work around the data.
</Callout>

## The shortest useful mental model

Every Pawabase project has one or more environments. In an environment you configure:

- **Data** — resources, fields, relations, validation, and generated APIs.
- **Access** — authentication, roles, organizations, and policies.
- **Behavior** — flows, events, queues, scheduled work, functions, and webhooks.
- **Services** — storage and realtime connections for your application.
- **Operations** — logs, failed jobs, secrets, API keys, environments, and promotion.

Studio turns those settings into a running backend. Your application calls the public interfaces exposed by that environment.

```text
Your web, mobile, or server application
                 │
                 ▼
       Pawabase environment
   auth · data · storage · flows
   events · jobs · webhooks · realtime
                 │
                 ▼
       database and external systems
```

## A deliberate learning path

### Beginner path

```text
Mental model → Project → Resource → Auth → Policy → Application → Flow → Realtime → Production
```

The [Quickstart](/quickstart) gets you moving. The [first-project tutorial](/tutorial/first-project) then adds the parts that make a backend useful in practice: private data, relations, automation, and live updates.

### Production path

Once basic CRUD works, learn to trace a complete operation through Pawabase:

```text
Application request
    ↓
Authentication and policy
    ↓
Validation and database operation
    ↓
Event or queued work
    ↓
Flow, function, webhook, or scheduled job
    ↓
Realtime update and operational record
```

The [Flows](/flows/overview), [Events](/events/overview), [Jobs](/jobs/queues), and [Observability](/operate/observability) sections explain how to build and operate that kind of system.
